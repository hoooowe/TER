# classroom-emotion

**教师情感识别** — 本分支只做一件事：**教学情绪-行为双维自动编码**。

面向微格 / 模拟教学场景，上传教学视频后，系统自动识别：

- **教学行为**：知识讲解、提问互动、板书演示、课堂组织、授课失误等（B1–B15）
- **可观察教学情绪**：放松平和、愉悦亲和、热情振奋、客观中性、紧张拘谨、枯燥敷衍，以及无法观测时的 X0

识别结果在同一时间轴上对齐（一个片段 = 一个行为码 + 一个情绪码），可人工复核后导出标准化双维编码表，供研究分析使用。

技术上采用通义语音识别 + 多模态大模型完成自动编码，界面支持逐段展示与在线修改。

---

## 一、编码体系

一个编码单元 = 一个时间段 + 一个行为码 + 一个情绪码，两维共用同一条时间轴。

### 行为编码（CTBAS 功能化重构）

| 维度 | 编码 |
|---|---|
| 知识讲授 | B1 知识讲解、B2 举例说明、B3 归纳总结 |
| 教学互动 | B41 全班提问、B42 个体提问、B43 追问、B5 回应反馈、B6 自主作答、B7 评价激励、B8 刻意停顿 |
| 教学操作 | B9 板书书写、B10 操作课件、B11 教学演示 |
| 课堂组织 | B12 组织活动、B13 活动说明、B14 环节过渡 |
| 失误行为 | B15 授课失误 |

### 情绪编码（V-A 模型离散化）

| 维度 | 编码 |
|---|---|
| 积极情绪 | E1 放松平和、E2 愉悦亲和、E3 热情振奋 |
| 中性情绪 | U1 客观中性 |
| 消极情绪 | N1 紧张拘谨、N2 枯燥敷衍 |
| 特殊状态 | X0 不可观测 |

> 编码定义（含每条的可观察线索描述）见 `backend/core/coding_framework.py`，导出文件的「编码手册」sheet 会一并把它们写出来。

## 二、过程指标

`compute_process_metrics()` 计算 8 个过程性指标，公式统一为：

```
指标 = 该组编码的出现次数 ÷ 同类事件总数     （0–1 小数，页面渲染为百分比）
```

其中 `N_b` = 全部有效行为事件数，`N_e` = 全部有效情绪事件数。

### 行为类（分母 = N_b）

| 缩写 | 中文名称 | 分子包含的编码 |
|---|---|---|
| KPBR | 知识呈现行为占比 | B1 B2 B3 |
| IIBR | 教学互动行为占比 | B41 B42 B43 B5 B6 B7 B8 |
| IOBR | 教学操作行为占比 | B9 B10 B11 |
| COBR | 课堂组织行为占比 | B12 B13 B14 |
| TEOR | 失误行为发生率 | B15 |

英文全称按缩写还原的常见读法：Knowledge Presentation Behavior Ratio、Instructional Interaction Behavior Ratio、Instructional Operation Behavior Ratio、Classroom Organization Behavior Ratio、Teaching Error Occurrence Rate，论文引用时以中文名为准。

### 情绪类（分母 = N_e）

| 缩写 | 中文名称 | 分子包含的编码 |
|---|---|---|
| PER | 积极情绪出现率 | E1 E2 E3 |
| NER | 中性情绪出现率 | U1 |
| NGR | 消极情绪出现率 | N1 N2 |

### 三个必须注意的口径

**1. 按「事件数」算，不按「时长」算。**
一个编码单元计为一个事件，板书 5 秒和讲授 5 分钟权重相同。KPBR 高不等于讲授时间长，只表示讲授类行为在行为事件中个数多。若论文口径要求按时长计算（如「知识呈现时长占比」），需修改 `compute_process_metrics()` 中的 `ratio()`，把计数 `+1` 换成累加 `duration`。

**2. 行为五项相加 = 1，情绪三项通常 < 1。**
B1–B15 被五组完整覆盖，无遗漏码。情绪侧多出一个 X0 不可观测：它被计入分母 `N_e`，但不进入任何一组的分子，因此

```
PER + NER + NGR ≤ 1       缺口 = X0 占比
```

举例：PER 0.4 + NER 0.3 + NGR 0.0 = 0.7，意味着这节课有 30% 的时段机器无法判断情绪（背对镜头板书、面部遮挡、声音缺失）。这个缺口本身往往比三项指标更值得写进分析——通常指向板书/背身过多。

**3. 分母只收合法编码。**
出现不在编码表内的异常码时会被跳过，不计入分子也不计入分母，不会污染比例。

### 怎么读

- **KPBR / IIBR** 这一对最能反映教学取向：KPBR 高、IIBR 低偏讲授灌输；IIBR 高偏互动探究。
- **TEOR** 非零即值得关注，是异常信号。
- **PER / NER / NGR** 必须与 X0 缺口一起报告，单独报告会有误导。

## 三、转移矩阵

`build_transition_matrices()` 统计**相邻序对**的出现次数，反映编码的序列结构。过程指标与矩阵互补：指标看总量分布，矩阵看流转路径。两节课 KPBR 同为 0.5，可能一节课讲练交替（转移频繁、对角线弱），另一节前半讲后半练（路径集中），这种差异只有矩阵能看出。

| Sheet | 含义 |
|---|---|
| 行为连接矩阵 | 行 = 前一行为，列 = 后一行为 |
| 情绪转换矩阵 | 行 = 前一情绪，列 = 后一情绪 |
| 行为情绪共现矩阵 | 行 = 情绪，列 = 行为，同一单元内的共现次数 |

## 四、人工复核与导出

### 界面操作

- 文本、行为码、情绪码均可直接编辑；改动过的单元格会打「已改」标记并高亮。
- 表头筛选：「仅看待复核」「仅看已修改」。
- **复核列提供「全选」复选框**（含半选态），作用于**当前筛选后的列表**。常见用法：先点「仅看待复核」，再点全选，即可一键把全部待复核项标记为已复核；再点一次整批取消。
- `needs_review` 只由模型给出，`review_marked` 只记录人工操作，两者独立，取消复核后该项会正常回到待复核列表。

### 导出结果同时保留 AI 原始值与人工修改值

Excel 与 CSV 表头完全一致，均为 24 列，每一维都拆成「AI 原始」与「人工」两组，逐行对照：

```
# | 开始时间 | 结束时间 | 时长
AI 原始文本 | 人工修正文本 | 文本是否修改
AI 原始行为码 | AI 原始行为名称 | 人工行为码 | 人工行为名称 | 行为维度 | 行为判定依据 | 行为是否修改
AI 原始情绪码 | AI 原始情绪名称 | 人工情绪码 | 人工情绪名称 | 情绪维度 | 外显情绪线索 | 情绪是否修改
置信度 | 待人工复核 | 已人工复核
```

被人工改动过的单元格标浅蓝底，待复核行标浅黄底。

### Excel 的 7 个 sheet

| Sheet | 内容 |
|---|---|
| 双维编码表 | 主表，24 列，AI 原始 / 人工双列对照 |
| 编码手册 | 全部行为码与情绪码的定义和可观察线索 |
| 过程指标 | 每个指标给出 **AI 原始**、**人工修正**、**差值**三列，差值非零标红底，便于评估人工修订对结论的影响 |
| 人工修改对照 | 一条修改一行（文本 / 行为编码 / 情绪编码），列出 AI 原始值、人工修改值、是否已复核 |
| 行为连接矩阵 | 上下两块：**AI 原始结果** + **人工修正结果** |
| 情绪转换矩阵 | 同上 |
| 行为情绪共现矩阵 | 同上 |

无任何修改时，「AI 原始」与「人工修正」两列数值完全一致；服务端直接导出（未走前端编辑）的旧路径由于对象不带 `original_*` 字段，会自动回退到当前值，同样一致。

> `AI 原始` 的计算方式：把每个单元还原为 `original_behavior_code` / `original_emotion_code` 后重新跑一次指标与矩阵，而非直接沿用服务端缓存值，因此人工改动对结论的影响是可量化的。
